# Carteira do Dragão

Aplicativo instalável e offline para controlar as moedas dos personagens.

- 1 Coroa = 20 Xelins = 240 Pences
- Dados guardados localmente no navegador do aparelho
- Histórico de ganhos e gastos, incluindo saldo negativo
- Backup em arquivo JSON

## Usar no computador

```bash
npm install
npm run dev
```

Abra o endereço indicado no terminal. Para instalar no celular, publique os arquivos criados por `npm run build` em uma hospedagem estática com HTTPS e use a opção **Instalar aplicativo** oferecida pelo navegador.

> Os dados não são sincronizados. Exporte um backup antes de trocar de navegador ou de celular.
